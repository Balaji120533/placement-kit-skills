# Test blueprints

These are practice mixes chosen for this kit. They are not any company's real pattern.

## General mock (default): 30 questions, 40 minutes

| Section | Questions |
| --- | --- |
| Quant | 10 |
| Logical reasoning | 5 |
| Verbal | 3 |
| C / Java output | 4 |
| Operating systems | 3 |
| DBMS and SQL | 3 |
| Computer networks | 1 |
| OOP | 1 |

## Short mock: 15 questions, 20 minutes

| Section | Questions |
| --- | --- |
| Quant | 5 |
| Logical reasoning | 3 |
| Verbal | 1 |
| C / Java output | 2 |
| Operating systems | 2 |
| DBMS and SQL | 1 |
| Computer networks or OOP | 1 |

## Other counts

Keep the same shares (about 60% aptitude, 40% technical), rounding so the section totals match the requested count. If the student gives a count but no time, allow about 80 seconds per question. If they give their own mix, use theirs.

Difficulty: about 30% easy, 50% medium, 20% hard. Vary the topics within each section; do not repeat one idea.

## Company mock

Build the sections, count and time from what the sources report. The sources often disagree, so state which figures you used and why. If they give no reliable mix, say "no reliable data" and use the general mock's mix, labelled as such.
