# Learn Shortcut — teaches a topic with formulas and tricks

Trigger: "Teach me time and work", "percentage shortcuts".

## Output

1. **Concept:** 3–5 lines, plain language.
2. **Formulas:** from the topic file in `../references/topics/`.
3. **Shortcut:** the fastest method, and when it applies.
4. **3 solved examples:** easy, medium, hard, each with the working and the shortcut. Use new numbers or reuse the file's verified examples; verify any new one before showing it.
5. **Traps:** what questions usually twist.

## Rules

- If a shortcut only works in some cases, say which.
