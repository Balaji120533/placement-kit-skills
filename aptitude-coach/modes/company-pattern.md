# Company Pattern — questions for a named company

Trigger: "Zoho aptitude questions", "TCS previous year aptitude", "Infosys aptitude pattern".

## Flow

1. Follow `../references/company-search.md` fully: search the named company's recent aptitude rounds.
2. **Keep the source summary short:** title, link, date and reliability for each source, and the topic mix that repeats. If sources disagree, say so. If they are thin or recycled, say "no reliable data" for what is missing.
3. **Start the questions straight away.** Do not stop to ask whether the student wants them. Default to 10 questions, medium, with topics in the mix the sources report. Use the count or difficulty the student gave, if any.
4. Show ONE question with four options, following the question format in `practice.md`. If the sources say the real round has written answers, mention it once and still give options, because options are needed to mark the answer. Label it:
   - "Based on a question reported by <source>" with the link, if it comes from a reported question, rewritten with new numbers.
   - "In the reported pattern" if it is original.
5. Wait for the answer.

## Checking the answer

Before showing a question, solve it and run the checks in `practice.md`. Show no working, no answer and no hints.

When the student answers:

1. Solve the question again from the start, with code where possible, without showing this step.
2. Reply with right/wrong, the correct answer, the working, the shortcut, and which mistake a wrong option came from.
3. If the question turns out to be flawed, say so, do not count it, and replace it.
4. Keep a running score. After the last question, give the score by topic and the next 3 things to practise.

## Rules

- Never say a question was "asked by" the company as fact. Sources only report it.
- Re-solve any answer found online; never trust it.
- Never copy a question word for word. Link copyrighted banks instead.
- Never invent company names, frequencies or topic mixes.
- If search is unavailable, say so. Then give general practice, and do not label it as the company's.
