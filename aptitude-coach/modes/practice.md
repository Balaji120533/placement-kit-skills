# Practice — topic-wise questions with instant explanation

Trigger: "10 percentage questions, medium", "seating arrangement practice".

## Flow

1. Confirm topic, difficulty and count (assume 10, medium if not given).
2. Show ONE question with four options. Wait for the answer.
3. After the answer: right/wrong, the correct option, the working, the shortcut, and which mistake the student's option came from if it was wrong.
4. Ask for the next question or move on. Keep a running score.

## The student's own question

When the student pastes a question instead of asking for a set:

1. Solve it fully and check the answer with code where possible. Do not generate a new question.
2. Give the answer, the working and the shortcut, and name the topic.
3. If options were given and none matches, say so and show your working. Do not pick the closest option.
4. If data is missing or more than one answer fits, say what is wrong with the question instead of forcing an answer.
5. Offer a similar original question.

## Difficulty

- **Easy:** one step, one formula.
- **Medium:** two or three steps, or a formula applied indirectly.
- **Hard:** two concepts combined, or a condition that is easy to miss.

## What makes a good question

- It tests one clear idea from the topic file and has realistic numbers.
- Every wrong option comes from a real mistake: a skipped step, the wrong base, an inverted ratio. Never use random numbers.
- All four options are different, in the same units and format, and only one is correct. Avoid "none of these" unless it is the answer in some questions too.
- All assumptions are stated (same rate, no replacement, facing the centre).
- Questions in a set vary in idea, not just in numbers.

## Checks before showing any question

| Section | Check |
| --- | --- |
| Quant | Compute the answer with code. Compute each option too, and confirm only one matches. |
| Seating, syllogisms, blood relations, direction | Enumerate every arrangement, or every set model, with code. Exactly one answer must survive. If more than one does, add a clue or discard the question. |
| Series, coding-decoding | Generate the sequence or code with code. Check that no other simple rule fits a different option. |
| Verbal | Code cannot check this. One option must be clearly best; state why each other option is wrong. Discard if two are defensible. |

If code can't be run, solve by two different methods, or by listing every case for puzzles. Tell the student the key was not executed. If you are not certain, discard the question and write a different one.

## Rules

- One question per response.
- Original questions only; no copying from question banks.
- Generate; do not search. For a company request, use `company-pattern.md`.
