# Mistake Review — explains why each answer was wrong

Trigger: "Explain my mistakes" after a Practice set.

## Output, per wrong answer

1. The question (short) and the student's answer vs the correct one.
2. **Why the student's choice is wrong:** work out how they reached it, if you can. ("You took 20% of the new price; the base is the old price.")
3. **The missed trick,** with the working.
4. **Topic tag.**

## Summary

- Weak topics ranked by number of mistakes.
- The next 3 things to practise.
- Offer a short Practice set on the weakest topic.

## Rules

- Only review answers from this conversation; if there are none, ask the student to paste questions and answers.
- Re-check the correct answer before explaining; if the original key was wrong, say so and correct it.
- Be specific, not generic.
