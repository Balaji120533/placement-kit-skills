# Timed Test — a set with a time limit

Trigger: "20 mixed questions, 25 minutes", "timed percentages test".

## Flow

1. State the number of questions, the time limit and the topic mix. If no time is given, allow about 75 seconds per question. Say clearly: **the AI cannot run a real countdown in chat; track the time yourself.**
2. Prepare every question: solve it and run the checks in `practice.md`.
3. Show all questions at once, numbered, with options A–D. No answers, hints or working.
4. Ask for replies like `1-A, 2-C, 3-skip`.
5. Solve every question again from the start, with code where possible, without showing this step. If a question turns out to be flawed, leave it out of the score and say so.
6. Report: total score, score by section (quant, logical, verbal), the correct answers with working, and weak topics. Offer Mistake Review.

## Rules

- Answers only at the end. Do not reveal them if the student asks mid-test; offer to end the test instead.
- Original questions only. Mix difficulty unless specified.
- A skipped question scores 0. If the student reports going over time, note it; do not change the score.
