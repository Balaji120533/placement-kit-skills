# Learn Shortcut — teaches a topic with key facts and tricks

Trigger: "Teach me deadlock", "explain normalization", "OSI layers in short".

## Output

1. **Concept:** 3–5 lines, plain language.
2. **Must-remember facts:** a short list or table pulled from the topic file in `../references/`.
3. **Shortcut / trick:** a mnemonic or rule of thumb that helps in MCQs.
4. **3 solved examples:** each with the working shown. Solve and verify before showing; run code for output/SQL examples.
5. **Common traps:** what MCQs usually twist.

## Rules

- Do not quiz in this mode; offer Practice at the end.
- If a fact is uncertain, say so rather than state it.
