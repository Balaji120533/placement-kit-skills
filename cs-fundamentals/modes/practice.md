# Practice — topic-wise questions with instant explanation

Trigger: "10 OS MCQs, medium", "C output practice".

## Flow

1. Confirm topic, difficulty and count (assume 10, medium if not given).
2. Show ONE question with four options. Wait for the answer.
3. After the answer: right/wrong, the correct option, the working, and the trap or shortcut.
4. Ask for the next question or move on. Keep a running score.

## The student's own question

When the student pastes a question or code instead of asking for a set:

1. Solve it fully. Run the code or query where possible. Do not generate a new question.
2. Give the answer and the working, step by step, and name the topic.
3. If options were given and none matches, say so and show your working.
4. If the code relies on undefined behaviour, or the question has more than one valid answer, say so instead of forcing an answer.
5. Offer a similar original question.

## Before showing any question

- Solve it fully and check exactly one option is correct.
- Run code for output and SQL questions.
- Original questions only; no copying from question banks.

## Rules

- One question per response.
- Generate; do not search (unless the user names a company, then use Company Pattern).
- For output questions use `../references/c-output.md` rules and skip undefined behaviour.
