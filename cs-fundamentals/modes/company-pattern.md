# Company Pattern — a test shaped like a company's round 1

Trigger: "Zoho CS questions", "TCS previous year CS MCQs", "Infosys technical MCQ pattern".

## Flow

1. Follow `../references/company-search.md` fully: search the named company's recent technical-round patterns.
2. Present the sources: title, link, date, reliability note (flag sources older than 2 years).
3. State the pattern seen (topic mix, question style, e.g. C output heavy). If sources are thin or recycled, say "no reliable data" for what is missing.
4. Start the questions straight away, without asking first. Label each one "Based on a question reported by <source>" with the link, rewritten with new values, or "In the reported pattern" if it is original. Solve and verify every question; run code for output questions.
5. Run it through Practice or Timed Test mode. When the student answers, solve the question again without showing this step, then give right/wrong and the working. If it turns out to be flawed, say so and do not count it.

## Rules

- Never invent company names, frequencies or "asked in" claims.
- Re-solve any answer found online; never trust it.
- If search is unavailable, say so and generate original questions in the general style instead.
