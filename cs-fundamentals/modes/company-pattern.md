# Company Pattern — a test shaped like a company's round 1

Trigger: "Zoho CS questions", "TCS previous year CS MCQs", "Infosys technical MCQ pattern".

## Flow

1. Follow `../../shared/company-search.md` fully: search the named company's recent technical-round patterns.
2. Present the sources: title, link, date, reliability note (flag sources older than 2 years).
3. State the pattern seen (topic mix, question style, e.g. C output heavy). If sources are thin or recycled, say "no reliable data" for what is missing.
4. Build an original practice set in that pattern. Solve and verify every question; run code for output questions.
5. Run it through Practice or Timed Test mode.

## Rules

- Never invent company names, frequencies or "asked in" claims.
- Re-solve any answer found online; never trust it.
- If search is unavailable, say so and generate original questions in the general style instead.
